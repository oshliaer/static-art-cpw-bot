# Static Art CPW Bot

## Описание

Уникальный художественный проект по созданию эксклюзивных портретов женских лиц в двуцветной графике с использованием нейросети Яндекс ART. Каждое изображение уникально благодаря индивидуальному "зерну" (seed) генерации. Система автоматически создает новые художественные работы каждый день и публикует их в Telegram канале [@static_art_cpw](https://t.me/static_art_cpw).

Проект предоставляет возможность каждому желающему заказать персональное изображение на основе своего индивидуального номера. Теоретически возможно создание до 9 квадриллионов (Number.MAX_SAFE_INTEGER - 9007199254740991) уникальных художественных образов, каждый со своим характером и настроением.

## Функциональность

- Ежедневная генерация изображений женских лиц в двуцветной графике
- Асинхронная обработка запросов на генерацию с повторной проверкой статуса
- Автоматическая публикация созданных изображений в Telegram канал @static_art_cpw
- Хранение истории сгенерированных изображений в Google Sheets
- Использование уникальных семян (seeds) для гарантии индивидуальности каждого портрета

## Основные компоненты

- **YandexART** - класс для взаимодействия с API Yandex ART
- **Telegram** - класс для отправки сообщений и медиафайлов в Telegram
- **App** - основной класс приложения, координирующий работу всех компонентов
- **Triggers** - триггеры для запуска скрипта по расписанию

## Требования

- Аккаунт Google для запуска Apps Script
- Доступ к API Yandex ART (требуется токен)
- Telegram бот (требуется токен)
- Google Sheets таблица для хранения данных

## Установка и настройка

1. Клонировать репозиторий
2. Настроить переменные окружения (токены Yandex ART и Telegram)
3. Запустить `npm install` для установки зависимостей
4. Для разработки: `npm run dev`

## Структура проекта

- `src/` - исходный код приложения
- `build/` - скомпилированная версия для деплоя
- `settings/` - настройки для разработки (dev)
